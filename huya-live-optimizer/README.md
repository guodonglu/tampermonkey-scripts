# 虎牙直播画质优化与观影增强器 (HuyaLiveOptimizer)

专为 [虎牙直播 (huya.com)](https://www.huya.com) 打造的现代化、全自动画质解锁、观影模式切换与片头广告秒跳脚本。

免手机扫码限制、自由享受原画/蓝光最高画质、自动进入网页全屏（观影模式）、毫秒级跳过片头广告，并提供精致优雅的暗色毛玻璃控制面板与单页路由（切台）自适应。

---

## ✨ 核心特性

1. **🔓 自动解锁画质扫码限制**：
   * 自动解除虎牙播放器对高画质（原画、蓝光8M、蓝光4M等）的手机端扫码登录限制。
   * 无需下载 APP 或手机扫码，打开直播间即可直接畅享最高规格画质。
   * 包含**动态解锁机制**，即使后续手动悬停（Hover）或点击清晰度菜单，也能保证限制被实时解除，不再弹扫码提示窗。

2. **🎯 智能画质自适应切换**：
   * 支持指定偏好画质级别：**最高画质（第一项，默认）**、**原画优先**、**蓝光优先**、**超清优先**、**高清优先**。
   * 若直播间不存在所选偏好画质，自动平滑回退至该直播间可用的最高画质。
   * 智能检测当前实际画质，避免重复点击引起的画面卡顿或重新拉流。

3. **🎬 自动进入观影模式（网页全屏 / 展开半屏）**：
   * 进入直播间后自动触发播放器网页全屏，隐藏冗余页面装饰，获得沉浸式巨幕观播体验。
   * **进入页面 10 秒高频轮询保障（每秒 1 次）**：自适应虎牙播放器异步渲染、控制栏延迟挂载与切台场景，全自动捕捉按钮并触发点击，进入全屏后自动停止，绝不漏点与回弹。
   * 避免直接浏览器全屏导致的切屏不便，与页面右侧弹幕及控制条完美融合。
   * 支持通过油猴菜单或设置面板随时一键切换。

4. **⏭️ 高性能片头广告秒跳**：
   * 废除低效且卡顿的全页面暴力 DOM 轮询，针对虎牙官方片头广告容器进行毫秒级精准捕捉。
   * 自动快速点击「跳过广告」控件，并在支持的环境下自动快进片头广告视频与静音。
   * 任务超时（15秒）或跳过完成后自动释放资源，0 冗余性能消耗。

5. **🧭 单页应用（SPA）与切台监听**：
   * 深度适配虎牙单页路由架构（`pushState` / `replaceState` / `popstate` / `hashchange`）。
   * 从列表页、侧边栏或推荐位换主播切台时，无需刷新网页，脚本自动重新触发画质解锁与优化流程。

6. **🎨 暗色毛玻璃控制面板与快捷悬浮徽标**：
   * 页面右下角常驻轻量胶囊徽标 `⚡ 虎牙优化 [原画]`，实时显示当前画质状态，点击呼出设置面板。
   * 采用现代化暗黑毛玻璃风格（Glassmorphism），支持独立开关各项功能、切换目标画质，并提供「🚀 立即运行优化」一键重跑。
   * 完美适配独立 CSS 命名空间，绝不污染页面原有样式，支持在设置中彻底隐藏悬浮徽标。

## 🚀 安装步骤

1. 确保浏览器已安装脚本管理器扩展：
   * [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)（推荐）
   * [Violentmonkey (暴力猴)](https://violentmonkey.github.io/)
   * [ScriptCat (脚本猫)](https://scriptcat.org/)
2. 打开脚本管理器，选择「添加新脚本」。
3. 打开 [`huya-live-optimizer.user.js`](./huya-live-optimizer.user.js)，复制全部代码并粘贴覆盖进编辑器中。
4. 按 `Ctrl + S` 保存。
5. 打开任意 [虎牙直播间](https://www.huya.com/102411)，尽情享受最高画质与沉浸式观播！

## ⚙️ 个性化配置说明

点击右下角「⚡ 虎牙优化」徽标，或点击浏览器工具栏的油猴图标选择「⚙️ 虎牙直播优化设置」呼出设置卡片：

- **🔓 解锁扫码画质限制**：开启后移除虎牙高画质扫码弹窗拦截（默认开启）。
- **🎯 偏好目标画质**：
  - `最高画质`（默认）：优先选择画质列表第一项。
  - `原画 优先`：检测并优先切换至原画规格。
  - `蓝光 优先`：检测并优先切换至蓝光规格。
  - `超清 优先`：适合宽带或配置较低的场景。
  - `高清 优先`：低码率省流模式。
- **🎬 自动进入观影模式**：进入房间后自动切换至网页全屏（默认开启）。
- **⏭️ 自动跳过片头广告**：检测并点击片头广告跳过按钮（默认开启）。
- **🧭 路由与切台监听**：单页切换直播间时自动重新应用优化（默认开启）。
- **📌 显示右下角悬浮徽标**：是否在右下角展示快捷状态入口（关闭后仍可通过油猴扩展菜单呼出设置）。
