# 虎牙直播主播屏蔽器 (油猴脚本)

一个专为 [虎牙直播 (huya.com)](https://www.huya.com) 设计的纯净、高效、无感的主播过滤与屏蔽脚本。支持通过**房间号 ID、直播间网址、个性域名或主播昵称**一键屏蔽。

---

## ✨ 核心特性

1. **仅在列表页展示悬浮标签，详情页不打扰**：
   * 页面右侧常驻的「🛡️ 屏蔽管理」悬浮标签**仅在列表页（首页、分类页、全部直播、搜索页等）显示**。
   * 进入主播直播间详情页时**自动隐藏悬浮标签**，观播沉浸无遮挡。
   * 在任何页面均可通过快捷键 **`Alt + H`** 或浏览器工具栏的**油猴菜单**一键呼出管理面板。
2. **列表页卡片彻底隐藏 (直接看不到)**：
   * 完美适配虎牙分类页（`/g/*`）、全部直播（`/l`）、首页及搜索页的动态模板渲染机制。
   * 深度解析卡片绑定的 `data-url`、`href`、`data-lp`、`data-uid` 及主播昵称标签（`.nick`），匹配即赋予 `display: none !important;`，卡片瞬间消失，后续卡片无缝补位。
3. **多维度灵活屏蔽**：
   * **房间号 / 域名**：如 `229085`、`333003`、`kpl`。
   * **直播间链接**：直接粘贴 `https://www.huya.com/229085`。
   * **主播昵称（支持模糊匹配）**：输入主播名字（如 `红莲`、`神超`、`弃徒`），输入 `红莲` 即可自动屏蔽 `红莲8888`。
   * **卡片悬停一键屏蔽**：鼠标悬停在卡片上浮现「🚫 屏蔽」按钮，点击直接屏蔽并隐藏。
   * **油猴菜单一键屏蔽**：在任意直播间内，点击油猴插件菜单里的「🚫 屏蔽当前直播间」即可直接屏蔽。
4. **误入直播间自动拦截与静音**：
   * 若不小心通过外链点入已屏蔽主播的房间，脚本**立刻静音并暂停视频**。
   * 弹出提示遮罩，提供「返回首页」、「解除屏蔽」或「临时进入」选项（可在设置中开启自动返回首页）。
5. **便捷配置导入与导出**：
   * 支持将屏蔽黑名单导出为 JSON 文件，或导入外部配置，便于多设备多浏览器无缝同步。

## 🚀 安装步骤

1. 确保浏览器已安装以下脚本管理器之一：
   * [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)（推荐）
   * [Violentmonkey (暴力猴)](https://violentmonkey.github.io/)
   * [ScriptCat (脚本猫)](https://scriptcat.org/)
2. 打开脚本管理器，选择「添加新脚本」。
3. 打开 [`huya-streamer-blocker.user.js`](./huya-streamer-blocker.user.js)，复制全部代码并粘贴覆盖进编辑器中。
4. 按 `Ctrl + S` 保存。
5. 访问或刷新 [虎牙直播 (huya.com)](https://www.huya.com)，在列表页右侧即可看到「🛡️ 屏蔽管理」标签！

---

## ⌨️ 快捷键与入口

* **呼出/隐藏管理面板**：
  * 点击列表页右侧悬浮条「🛡️ 屏蔽管理」
  * 按键盘快捷键 **`Alt + H`**（所有页面通用）
  * 点击浏览器扩展栏的油猴图标 -> 选中「⚙️ 虎牙主播屏蔽管理面板」
* **快捷屏蔽**：
  * 鼠标悬停在直播卡片上，点击右上角浮现的「🚫 屏蔽」小按钮。
