# 虎牙直播全方位广告与干扰元素屏蔽器 (油猴脚本)

一个专为 [虎牙直播 (huya.com)](https://www.huya.com) 打造的现代化、纯净、全方位的广告与干扰元素过滤脚本。

消除一切遮挡视频与聊天栏的商业广告、营销挂件、二维码弹窗与牛皮癣推广，还原极致清爽流畅的观播体验。

---

## ✨ 核心特性

1. **聊天栏商业横幅彻底净化与自适应顶格**：
   * 彻底移除聊天栏上方恶心遮挡的商业横幅广告（如麦当劳等全屏大图）。
   * 广告移除后，右侧聊天室区域**自动向上延伸顶格铺满**，高度完美自适应，告别大块空白或页面断层。
2. **播放器悬浮营销挂件全屏蔽**：
   * 全面屏蔽遮挡视频画面的交互挂件与浮动图标，包括：「小黄车」、「上热门」、「甜蜜互动」、「更多活动」图标、宠物图标等。
   * 屏蔽内置的互动 iframe 扩展插件（虎牙小程序），不再误触遮挡游戏画面。
3. **播放器二维码与 APP 下载浮层拦截**：
   * 彻底隐藏视频画面左下角常驻的黄脸吉祥物与「下载 虎牙直播APP 精彩赛事随时享」二维码。
4. **营销礼包与抽奖百宝箱隐藏**：
   * 隐藏浮动宝箱动画、周星打榜入口、礼物栏「首充礼包」、百宝箱等充值诱导入口。
5. **视频水印与角标广告清除**：
   * 屏蔽播放器右上角的虎牙官方水印（Logo），享受无水印原画级画面。
   * 屏蔽暂停广告与播放器右下角弹窗角标。
6. **聊天区纯净模式**：
   * 屏蔽聊天列表顶部的长篇巡查警告系统消息与富文本推广卡片。
   * 支持按需开启屏蔽「进场座驾广播」与「小额荧光棒送礼滚屏」，弹幕交流更专注。
7. **零延迟渲染与无感注入**：
   * 采用 `document-start` 动态样式注入引擎，页面在网络加载瞬间即完成过滤规则匹配，**绝无广告先闪现再消失的肉眼闪烁现象**。
8. **现代化控制面板与实时统计**：
   * 右下角常驻轻量级半透明状态徽标，实时显示当前页面已拦截的广告元素数量。
   * 点击即可呼出暗色毛玻璃风格设置面板，各项功能均可单独开关并一键保存。
   * 支持通过浏览器扩展栏的**油猴菜单**呼出面板，也可在设置中彻底隐藏右下角悬浮标。

## 🚀 安装步骤

1. 确保浏览器已安装脚本管理器扩展：
   * [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)（推荐）
   * [Violentmonkey (暴力猴)](https://violentmonkey.github.io/)
   * [ScriptCat (脚本猫)](https://scriptcat.org/)
2. 打开脚本管理器，选择「添加新脚本」。
3. 打开 [`huya-ad-blocker.user.js`](./huya-ad-blocker.user.js)，复制全部代码并粘贴覆盖进编辑器中。
4. 按 `Ctrl + S` 保存。
5. 打开任意 [虎牙直播间](https://www.huya.com/102411)，尽情享受纯净无广告的观播体验！

## ⚙️ 快捷控制与自定义项

点击页面右下角「🛡️ 纯净模式 [数字]」徽标，或点击浏览器工具栏的油猴图标选择「⚙️ 虎牙广告拦截与纯净设置」：

- **聊天栏商业横幅广告** (默认开)
- **播放器悬浮营销挂件** (默认开)
- **播放器二维码与APP下载** (默认开)
- **宝箱与营销礼包入口** (默认开)
- **播放器画面水印** (默认开)
- **顶部头图背景与活动横幅** (默认开)
- **游戏推广与页脚推荐** (默认开)
- **聊天区系统宣传长文** (默认开)
- **进场座驾与贵族广播** (可选开启)
- **聊天区小额送礼滚屏** (可选开启)
- **自动关闭未登录弹窗** (可选开启)
- **显示右下角管理悬浮标** (可随时切换)
