# ⚡ 虎牙全能助手 (Huya All-in-One Toolkit)

> 专为 [虎牙直播 (huya.com)](https://www.huya.com) 打造的现代化、一体化全功能增强与纯净净化油猴脚本。
> 将 **画质解锁优化**、**全方位广告屏蔽** 与 **主播黑名单过滤** 三大核心功能完美融为一体，提供多标签暗色毛玻璃控制中心与智能状态徽标。

## 🌟 核心特性全览

### 📺 1. 画质解锁与观影增强
* **🔓 自动免扫码解锁全画质**：彻底解除原画、蓝光8M/4M等清晰度的手机客户端扫码绑定限制，支持动态悬停与点击实时解锁。
* **🎯 智能画质自适应切换**：优先自动切换至最高画质或偏好画质（原画/蓝光/超清/高清），画质不存在时自动平滑回退，防止重复加载卡顿。
* **🎬 自动进入观影模式（网页全屏）**：进入直播间自动展开为沉浸式网页全屏，并提供进入后 10 秒轮询保障，绝不回弹。
* **⏭️ 片头广告毫秒级跳过**：高精度识别跳过按钮并自动快进静音，广告结束后自动释放监听，0 冗余 CPU 占用。
* **🧭 单页 SPA 切台监听**：深度适配单页路由，换主播切台无需刷新，自动重新应用画质与全屏。

### 🛡️ 2. 全方位广告与干扰元素净化
* **💬 聊天室商业横幅广告清除**：彻底消除聊天栏上方的商业大图横幅（如麦当劳等），聊天列表**自动向上顶格自适应伸展铺满**。
* **🛒 播放器悬浮营销挂件全屏蔽**：全面清理小黄车、上热门、甜蜜互动、更多活动、扩展 iframe 小程序等画面遮挡物。
* **📱 APP 下载二维码与吉祥物拦截**：隐藏左下角黄脸吉祥物及「下载虎牙直播APP」常驻二维码。
* **🎁 充值诱导与营销活动清除**：屏蔽浮动百宝箱、首充礼包、周星榜、抽奖转盘等营销入口。
* **💧 官方水印移除**：屏蔽播放器右上角常驻虎牙 Logo 水印，享受 100% 纯净原画画面。
* **📢 聊天区系统牛皮癣推广净化**：过滤聊天室顶部大段巡查警告长文与富文本卡片；支持按需开启屏蔽贵族进场座驾与小额送礼滚屏。
* **⚡ 0 CPU 纯 CSS 秒级渲染**：采用 `document-start` 动态样式注入引擎，网络加载瞬间生效，绝无广告闪现现象。

### 🚫 3. 主播过滤与黑名单屏蔽
* **🔍 多维度智能屏蔽**：支持输入**房间号数字 ID**、**个性域名**、**直播间完整网址**或**主播昵称（支持模糊匹配）**一键屏蔽。
* **👁️ 列表页彻底隐藏卡片**：在首页、分类分区页（`/g/*`）、全部直播（`/l`）及搜索页，匹配卡片直接赋予 `display: none !important;`，后方卡片顺畅补位。
* **🖱️ 卡片悬停一键快捷屏蔽**：鼠标悬停在直播卡片右上角时浮现「🚫 屏蔽」小按钮，点击瞬间屏蔽并隐藏。
* **🛑 误入直播间拦截与静音**：若通过外部链接误入已屏蔽主播的直播间，立刻停止视频画面与声音播放，弹出友好提示遮罩（支持设置自动返回首页）。
* **💾 黑名单导入与导出**：支持一键导出与导入 JSON 格式黑名单，多设备、多浏览器无缝迁移。

### 🎨 4. 现代化多标签毛玻璃控制中心
* **🧩 统一智能胶囊徽标**：
  * 直播详情页：展示当前清晰度（`原画`）与广告拦截计数（`净 12`）。
  * 列表分类页：展示已屏蔽主播总数（`已屏蔽 3`）。
  * 支持自定义开启或完全隐藏。
* **🎛️ 四大标签分类管理**：
  1. `📺 画质与观影`
  2. `🛡️ 广告与净化`
  3. `🚫 主播黑名单`
  4. `⚙️ 全局设置`
* **🔄 向下兼容**：自动兼容并无缝继承原有各个单项脚本的历史配置与黑名单列表。

## ⌨️ 快捷操作与使用入口

| 操作方式 | 功能说明 |
| :--- | :--- |
| **快捷键 `Alt + H`** | 在虎牙任意页面随时呼出 / 关闭统一控制中心 |
| **按键 `Esc`** | 快速关闭控制中心弹窗 |
| **点击右下角胶囊徽标** | 点击 `⚡ 虎牙全能` 徽标快速打开控制中心 |
| **卡片悬停点击 `🚫 屏蔽`** | 在列表页悬停任意主播封面，点击右上角小按钮直接屏蔽 |
| **油猴扩展菜单** | 点击浏览器右上角脚本管理器图标，可使用：<br>• `⚙️ 打开虎牙全能控制中心`<br>• `🎬 切换网页全屏 / 观影模式`<br>• `🔄 立即重新优化当前画质`<br>• `🚫 屏蔽当前直播间` |
